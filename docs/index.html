The demo

Two prompts. Read, then write back.

01 · READ

Open the relationship

Claude fuzzy-matches the account, pulls opportunities, cases and contacts with live SOQL, and publishes the page filled like for like. Empty means empty; nothing is invented.

02 · CONSENT

The pop-up is the story

On first open, claude.ai asks the viewer to let the page use the sObject connector. The page acts with the viewer's own credentials, scoped to two tools. That dialog is the governance model, on stage.

03 · WRITE

Describe the case

The viewer's Claude drafts subject and priority from plain language. One confirm creates it in the org; the page re-reads the record and the new row lands with a violet wash. Check the org tab: it's there.

Under the hood

A skill, a page, two capabilities.

No app servers, no sync jobs. The agent follows a skill; the published page holds exactly two runtime grants.

Skill relationship-lens  drives the loop: resolve the account, read the book via live SOQL, fill the page's JSON data slot, publish, and handle natural-language writes from chat. Republishes always target the same artifact.
Capability · mcp Scoped to one connector, two tools: sObject → soqlQuery + createSobjectRecord. Live re-reads, Refresh, and in-page case creation run with the viewer's own Salesforce access.
Capability · sample The viewer's own Claude turns a plain-language description into a drafted case. If unavailable, the composer falls back to plain subject and priority fields.
Failure design Per-error reconnect copy, one retry on read timeouts, and never a blind retry on writes. A timed-out create re-reads before anything else. Ambiguous is treated as ambiguous.
Objects Standard only: Account, Opportunity, Case, Contact. Works against any org the connector can see.
Get it

Install in a minute.

# in claude.ai, Cowork or Claude Code /plugin marketplace add Connectry-io/relationship-lens /plugin install relationship-lens@relationship-lens # then, in a workspace with the sObject Salesforce connector: Open the <account name> relationship

Needs the sObject Salesforce MCP connector authorized in the workspace, and artifacts enabled.
If your workspace names the connector differently, say so when opening a relationship and the agent adjusts.
